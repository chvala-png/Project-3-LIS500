Our Project Statement

We created an algorithm and exported it into an API (application program interface) using Google's Teachable Machine. Our algorithm process the shape of the users hand, and outputs whether the user is making a thumbs-up, thumbs-down, peace sign, "rock on" sign, or a heart.
